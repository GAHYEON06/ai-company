AI 동료들을 깨워볼까요?

이 페이지는 내 PC에서만 열리는 연결 설정이에요.
API 키는 Windows 사용자 계정으로 암호화해 보관해요.

연결 프로그램을 확인하고 있어요.

키를 채팅이나 GitHub에 붙여 넣지 마세요. 저장된 키가 있다면 비워두어도 돼요.

여러 직원이 작업하면 API 사용량이 늘어날 수 있어요. 선택한 모델로 실행하며 자동으로 다른 모델로 바꾸지 않아요.

연결할 사무실:

연결된 사무실에서 이 PC의 AI에 업무를 전송할 수 있어요. OpenAI API 키는 사무실 웹사이트로 전달하지 않아요.
